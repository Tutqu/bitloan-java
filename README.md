# bitloan-java

BIT-LOAN, Java Program: Financial and academic student loan simulator; Choice based Role-Play-Game (RPG) models the life of a student as the user navigates education, career pathways, and financial responsibilities.

## Overview:
The program simulates the progression of a high school student into their first career. Randomly generated user details makes each play through unique, following the student throughout their education. Menu selected decisions enable user choices that positively or negatively impact the student's savings and pathway to applying for student loans. While the game does not penalize the player by ending, the objective remains as "achieving the user's desired career."

## Objective:
Research and implementation of fiscal data relevant to students to reinforce financial literacy and career planning via choice-based RPG's. The program aims to educate students in an engaging and relevant manner while emphasizing student responsibilities and consequences. 


## Features:
 - Randomized player data and attributes including family income, career plan, and province
 - Conditional level up system with a file I/O tracking
 - File I/O savings system, subject to increase/decrease based on user choices
 - Possibilities of in-game entrepreneurship and internship experience
 - Relevant taxation, province and federal information pertaining to student loans
 - Sample funding calculation system based on data
 - Main menu features that progress with leveling up
 - Game reset function
